# Code of Conduct

bQuery.js follows the project [Code of Conduct](https://github.com/bQuery/bQuery/blob/main/CODE_OF_CONDUCT.md). The full text lives in the repository root.

## In short

- Be welcoming. Be kind. Be patient.
- Discuss ideas, not people.
- Disagreement is fine; disrespect is not.
- Report unacceptable behaviour through the channels in the canonical document.

## Reporting

Reports should follow the contact path documented in [`CODE_OF_CONDUCT.md`](https://github.com/bQuery/bQuery/blob/main/CODE_OF_CONDUCT.md). Reports are confidential.
